ΕΣΠΑ Auto-Update 🚀

Πλήρως αυτοματοποιημένη ενημέρωση των προγραμμάτων ΕΣΠΑ. Ένα κλικ, όλα γίνονται αυτόματα.

Πώς λειτουργεί: Πατάς το bookmark στη σελίδα ΕΣΠΑ → το JavaScript διαβάζει τα προγράμματα → τα στέλνει στο Cloudflare Worker σου → ο Worker κάνει auto-commit στο GitHub → το app ενημερώνεται σε 1 λεπτό. Καμία manual ενέργεια.

Εγκατάσταση — μία φορά

💻Στον υπολογιστή:

Σύρε αυτό το κουμπί στη γραμμή αγαπημένων του browser:

🚀 Update ΕΣΠΑ

📱Στο κινητό:
  1. Πάτα το κουμπί Αντιγραφή παρακάτω:


  2. Στον browser, φτιάξε νέο bookmark (π.χ. αυτή τη σελίδα)
  3. Ονόμασέ το: Update ΕΣΠΑ
  4. Στο URL του bookmark, επικόλλησε τον κώδικα (αντικατάσταση του τρέχοντος URL)
  5. Αποθήκευση

Χρήση — όποτε θες

  1. Άνοιξε: espa.gr/el/Pages/Programmes_2021-2027.aspx
  2. Περίμενε να φορτώσει η σελίδα
  3. Πάτα το bookmark 🚀 Update ΕΣΠΑ
  4. Περίμενε 3-5 δευτερόλεπτα
  5. Θα δεις μήνυμα:
    • ✅ Επιτυχία! — Ν προγράμματα ανέβηκαν στο GitHub
    • ℹ️ Ενημερωμένο — τα δεδομένα ήταν ήδη ίδια
    • ❌ Σφάλμα — κάτι πήγε στραβά (στείλε μου το μήνυμα)

Πότε να το τρέχεις

Δεν χρειάζεται καθημερινά. Αρκεί:

  • Μία φορά την εβδομάδα ή τον μήνα
  • Όποτε ακούσεις για κάποιο νέο πρόγραμμα ΕΣΠΑ
  • Όταν θυμηθείς

Πηγαίνει κάτι στραβά;

Αν βλέπεις σφάλμα, οι πιο πιθανές αιτίες:

  • Σφάλμα δικτύου: επανάληψη — το espa.gr ή το Worker είναι προσωρινά κάτω
  • GitHub PUT failed 401: το token έληξε ή αφαιρέθηκε — φτιάξε νέο
  • 0 προγράμματα: δεν είσαι στη σωστή σελίδα, ή το espa.gr άλλαξε δομή (πες μου)
